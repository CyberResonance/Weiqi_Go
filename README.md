# Weiqi / Go Game (圍棋)

A digital implementation of the ancient strategy board game **Go (Weiqi)**. Built with **React** and **Vite**.

## 🌟 Features

- **Interactive Board**: Playable 19x19 grid (standard) with stone placement logic.
- **Game Rules**: (In Progress) Implementation of capture mechanics and territory scoring.
- **Clean UI**: Minimalist design focusing on the gameplay experience.

## 🚀 Getting Started

### Prerequisites

- Node.js (v14+)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Weiqi_Go.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Weiqi_Go
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

Start the development server:

```bash
npm run dev
```

## 🛠️ Build

To build for production:

```bash
npm run build
```
